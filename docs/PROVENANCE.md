## Scientific preservation

The retained functions in `research.py` preserve the selected WABAD source bodies; Input–Processing–Output docstrings and section comments have been added. Notebook-style defaults are loaded from a bundled JSON resource, reset before each serial run, and overridden only through an explicit settings dictionary. The main runner uses the supplied `compute_pipeline_for_file` and `gmm_boxes_from_cluster_drifts` functions. Detection excludes reference annotations.

Unused interactive plot helpers and the original peak/proxy/grid utilities remain in the expert research API for traceability. The main runner does not call the alternative peak-based final detector or perform grid-search selection. Every retained research function is listed in API_REFERENCE.md.

## User-facing changes

- Local Windows paths were removed from executable code; configurations are relative/absolute, editable JSON.
- Repeated notebook-wide pipelines were replaced with one selected WABAD implementation and two guided notebooks.
- Input discovery is deterministic, checks duplicate stems, and refuses ambiguous annotation matches instead of selecting a loose first match.
- Annotation reading uses explicit headers and rejects invalid coordinates instead of silently producing empty ground truth.
- Missing annotations and an intentionally empty table are distinguished.
- Output CSV headers exist even when no events are predicted.
- Completion markers are written after outputs and summaries; source/config/data/dependency fingerprints prevent stale reuse after changes.
- A new conditional evaluator reconstructs manuscript §4.2 in a separate module and namespace. It is not the original unpublished evaluation code.
- The author’s original ARD example figures are included unchanged. The notebooks and paper-example configuration require the corresponding real WABAD files from the planned study data release.
- Tests, CI configuration, dependency metadata and a planned data-release manifest are included.
- Prediction plots retain the supplied cyan/green convention; labels in the README/plot title explain it. Reference plotting retains the supplied per-label legend approach.
